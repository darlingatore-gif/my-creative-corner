# My Creative Corner

Crée une application web privée, pensée principalement pour iPhone, appelée provisoirement « Mon Atelier ».

L’application doit ressembler à un mélange de Pinterest, Milanote, GoodNotes et d’un carnet de scrapbooking numérique.

Pour cette première version, concentre-toi uniquement sur l’interface et la navigation. Ne crée pas encore de système complexe de connexion, de paiement ou de base de données.

Style visuel :

ambiance girly, douce, élégante et créative ;

esprit scrapbooking moderne ;

couleurs rose poudré, crème, beige, mauve clair et touches dorées ;

cartes aux coins arrondis ;

ombres légères ;

textures de papier discrètes ;

typographies élégantes mais très lisibles ;

stickers, rubans adhésifs décoratifs, trombones, petites fleurs et éléments dessinés à la main ;

rendu esthétique et adulte, pas enfantin ;

interface fluide et parfaitement adaptée à l’écran d’un iPhone.

Crée les pages suivantes :

Page d’accueil

un message de bienvenue ;

les carnets récemment ouverts ;

une section « Mes favoris » ;

un bouton visible « Créer un carnet » ;

une présentation en mosaïque inspirée de Pinterest.

Bibliothèque de carnets

affichage des carnets sous forme de jolies couvertures ;

possibilité de choisir un affichage en grille ou en liste ;

barre de recherche ;

filtres par catégorie, couleur et favoris ;

menu sur chaque carnet pour renommer, dupliquer, archiver ou supprimer.

Création d’un carnet

choix du titre ;

choix d’une couverture ;

choix d’une couleur ;

possibilité d’importer une image de couverture ;

plusieurs modèles visuels proposés.

Intérieur d’un carnet

affichage des pages ;

navigation simple entre les pages ;

bouton pour ajouter une nouvelle page ;

aperçu des miniatures des pages ;

design inspiré d’un véritable carnet ouvert.

Éditeur de page

grande zone de création libre ;

barre d’outils simple ;

boutons pour ajouter du texte, une photo, une vidéo, un sticker, une forme, un lien et une note ;

éléments déplaçables librement ;

possibilité de redimensionner et faire pivoter les éléments ;

choix de la couleur ou de la texture du fond ;

bouton annuler et rétablir ;

sauvegarde visuelle automatique simulée.

Mode lecture immersive

masquer tous les outils d’édition ;

afficher les pages en plein écran ;

navigation par glissement horizontal ;

ambiance calme et élégante ;

possibilité de lancer automatiquement les vidéos présentes sur une page.

Profil et réglages

photo ou avatar ;

préférences d’apparence ;

choix du thème clair ;

gestion des carnets archivés ;

bouton de déconnexion uniquement visuel pour le moment.

Navigation mobile :

barre de navigation fixe en bas ;

cinq onglets : Accueil, Carnets, Créer, Favoris et Profil ;

navigation facile avec le pouce ;

aucun menu compliqué ;

boutons suffisamment grands pour être utilisés sur iPhone.

Utilise des données fictives pour présenter plusieurs carnets d’exemple :

Journal de lecture ;

Inspirations ;

Souvenirs ;

Mon roman ;

Idées créatives.

Crée une première version complète, cohérente et très esthétique. Toutes les pages doivent être accessibles afin que je puisse tester la navigation. Les fonctions peuvent être simulées pour cette première maquette, mais l’interface doit sembler réaliste.
